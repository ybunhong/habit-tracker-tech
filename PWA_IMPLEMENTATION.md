## Caching Strategy Rationale

### Cache-First for Images
- **Why**: Images don't change frequently
- **Benefit**: Instant loading, reduced bandwidth
- **Trade-off**: May serve stale images (acceptable for 30 days)

### Network-First for API
- **Why**: Data freshness is critical for habit tracking
- **Benefit**: Always shows latest data, falls back to cache if offline
- **Trade-off**: Slightly slower initial load (network request first)

### Precache for App Shell
- **Why**: HTML, CSS, JS are version-controlled assets
- **Benefit**: Instant app loading, works offline immediately
- **Trade-off**: Requires cache busting on updates (handled by build)

## Deployment Instructions

### Vercel Deployment
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel

# For production
vercel --prod
```

### Netlify Deployment
```bash
# Install Netlify CLI
npm i -g netlify-cli

# Deploy
netlify deploy --prod
```

### Manual Deployment
1. Build the app: `npm run build`
2. Upload `dist/` folder to your server
3. Configure server to serve SPA (redirect all routes to index.html)
4. Enable HTTPS
5. Ensure service worker scope is root
